Help centre

Frequently asked questions.

Find general guidance about using the website and making an enquiry.

1. Which countries can use the form?

The country selector includes 54 African countries and sets the corresponding international calling code and currency.

2. How does the phone code work?

Select your country, then type the rest of your phone number without repeating the country calling code.

3. How is my currency selected?

The currency code is automatically linked to the country you choose. The amount you enter is interpreted in that displayed currency.

4. Can I choose the amount myself?

Yes. Enter the amount you want to enquire about. It does not by itself establish eligibility or confirm funds are available.

5. What happens when I submit?

The page prepares a summary, then lets you open WhatsApp with the details in a draft message.

6. Is the form an approval system?

No. This single-file website prepares enquiries only. A genuine programme needs a verified review process and real programme information.

7. How do I know programme details?

Ask for the organisation's registration details, written programme rules, eligibility requirements and official contact information.

8. Can I change my details?

Yes. Select Edit details in the review summary to return to the form.

9. Is the assistant a live person?

No. It is a preset question-and-answer guide. It does not make funding decisions or verify identities.

10. How can I protect my information?

Only share information that is necessary with a verified contact. Never share a password, mobile-money PIN or one-time security code.
